关于这个页面
这是 moxsh-suite 仓库的公开 GitHub Pages 索引页，只包含可公开的分发信息与仓库链接。 真正的官网、在线体验与文档站部署在 mox-site 的 Pages 上。

本仓的 site 子模块是私有维护者指针：匿名 CI / Pages 无法拉取，因此部署流程显式使用 submodules: false，不会尝试初始化子模块，也不会把私有内容发布到这里。

版本编排

子模块锁定提交由 scripts/sync-submodule-pins.mjs 从 git ls-tree HEAD 生成，中英双语 README 同步，并由 CI 在每次 push / PR 强校验；跨仓版本组合见仓库根目录的 compat-matrix.json（人工采集，非实时数据）。
